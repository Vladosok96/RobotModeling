# Учебный ROS 2-пакет UR5e

Пакет содержит тестовую сцену Webots R2023b, ROS 2 Humble-драйвер суставов и пример движения.

Развёртывание, команды ROS и порядок изменения сцены описаны в [инструкции репозитория](../../../README.md).

Основные файлы: `driver.py` — датчики и моторы; `trajectory.py` — точки и интерполяция; `demo.py` — тест движения; `webots/worlds/ur5e_lab.wbt` — сцена; `launch/lab.launch.py` — запуск. Python-модули расположены в `ur5e_student_lab/`.

Модели и ресурсы сохранены с атрибуцией в `LICENSE`, `THIRD_PARTY.md` и `ASSETS.tsv`.
